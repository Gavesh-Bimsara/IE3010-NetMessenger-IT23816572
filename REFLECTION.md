I used Claude (Anthropic’s AI assistant) throughout Part 1 of this assignment. I also used it during the design stage to understand how a -based concurrency model could work and how the program could handle both normal commands and file transfers.

One of the main benefits of using AI was that it helped me create a working first version in a short amount of time.
